
# Vehiclete 🚗

A unified vehicle platform. 

## 🚀 Getting Started (Local Setup)

Follow these steps to run the project locally on your machine.

### 1. Clone the repository
First, clone the project to your local machine and navigate into the project directory:
```bash
git clone [https://github.com/amgowda42/vehiclete.git](https://github.com/amgowda42/vehiclete.git)
cd vehiclete

```

### 2. Frontend Setup

Open a terminal, navigate to the `client` folder, install the dependencies, and start the development server:

```bash
cd client
npm install
npm run dev

```

### 3. Backend Setup

Open a **new** terminal window, navigate to the `api` folder, install the dependencies, and start the backend server:

```bash
cd api
npm install
npm run dev

```

## 🤝 Contributing

Vehiclete is an open-source project, and contributions are highly welcome! If you'd like to contribute, please follow these steps:

1. **Fork the repository** to your own GitHub account.
2. **Clone your fork** locally:
```bash
git clone [https://github.com/YOUR_USERNAME/vehiclete.git](https://github.com/YOUR_USERNAME/vehiclete.git)

```


3. **Create a new branch** for your feature or bug fix:
```bash
git checkout -b feature/your-awesome-feature

```


4. **Make your changes** and commit them with a descriptive message:
```bash
git commit -m "feat: added new awesome feature"

```


5. **Push your branch** to your forked repository:
```bash
git push origin feature/your-awesome-feature

```
